<Update label="October 17, 2026" tags={["API"]} description="AlexWeb API 1.1.0">
  ### AlexWeb API 1.1.0

  - Added scoped API keys and OAuth connections with PKCE.
  - Added registered applications, resources and live events.
  - Added signed webhooks, scheduled actions, usage and audit history.
  - Added request limits and a full API specification.
  - Added API support for a future Home Assistant integration. The integration itself will be built later.

  See [API Keys](/v1/api-keys) to connect and [Home Assistant](/v1/home-assistant) for integration support.
</Update>

<Update label="October 16, 2026" tags={["API"]} description="Base API 1.0.0">
  ### Base API 1.0.0

  - Added the version 1 Base endpoint at `GET /api/v1`, returning the API name and version.
  - Added the message echo example with JSON validation and request size limits.
  - Added health and OpenAPI specification routes.
  - Added JSON error responses and request IDs.

  See [Base API](/v1/base) for endpoint usage, examples, and error details.
</Update>
