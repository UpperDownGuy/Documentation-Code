<Update label="October 18, 2026" tags={["API","Docs"]} description="AlexWeb API 1.2.0">
  ### AlexWeb API 1.2.0

  - Added public developer signup and sign-in, with a separate account for each developer's keys, apps, data, and usage.
  - Added a [developer console](https://api.alexxweb.com/developers) for API keys, OAuth applications, request counts, response times, and errors.
  - Added API key rotation that replaces a key and immediately revokes the old key and its connected grants.
  - Added public readiness and status checks, including uptime and storage check response time, without exposing infrastructure details.
  - Added a daily quota shared by a registered developer account's authenticated API requests.
  - Improved these docs with centered action buttons, clearer starting points, and interactive API requests.

  See [Developer Accounts](/v1/developer-accounts) to get started, [Health & Status](/v1/status) to check availability, or [Usage](/v1/usage) to understand the metrics.
</Update>

<Update label="October 17, 2026" tags={["Integration"]} description="Home Assistant integration 1.0.0">
  ### Home Assistant integration 1.0.0

  - Added setup through the Home Assistant UI with an API key or OAuth with PKCE.
  - Added sensors, binary sensors, switches and text entities for AlexWeb resources.
  - Added live event updates, polling recovery and events for Home Assistant automations.
  - Added permission checks, version-protected commands and reauthentication.
  - Added a detailed installation and troubleshooting guide.

  See [Home Assistant](/v1/home-assistant) for setup and usage.
</Update>

<Update label="October 17, 2026" tags={["API"]} description="AlexWeb API 1.1.0">
  ### AlexWeb API 1.1.0

  - Added scoped API keys and OAuth connections with PKCE.
  - Added registered applications, resources and live events.
  - Added signed webhooks, scheduled actions, usage and audit history.
  - Added request limits and a full API specification.
  - Added API support for a future Home Assistant integration. The integration itself will be built later.

  See [API Keys](/v1/api-keys) to connect and [Home Assistant](/v1/home-assistant) for integration support.
</Update>

<Update label="October 16, 2026" tags={["API"]} description="Base API 1.0.0">
  ### Base API 1.0.0

  - Added the version 1 Base endpoint at `GET /api/v1`, returning the API name and version.
  - Added the message echo example with JSON validation and request size limits.
  - Added health and OpenAPI specification routes.
  - Added JSON error responses and request IDs.

  See [Base API](/v1/base) for endpoint usage, examples, and error details.
</Update>
