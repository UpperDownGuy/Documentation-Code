The Base API shows the API's name and current version.

## Try it

Open [https://api.alexxweb.com/api/v1](https://api.alexxweb.com/api/v1) in your browser.

You do not need to log in or provide an API key.

## What you'll see

```json
{
  "name": "base-api",
  "version": "1.0.0"
}
```

- **name** is the API's name.
- **version** is the current API version.

This request only reads information. It does not change anything.

## POST requests

```powershell
POST /api/v1/echo
```

Usage:

<CodeGroup>

```powershell CURL
curl https://api.alexxweb.com/api/v1/echo \
  -H "Content-Type: application/json" \
  -d '{"message":"hello"}'
```

</CodeGroup>

Response:

```json
{
  "message": "hello"
}
```

Body:

```json
{
  "message": "hello"
}
```
