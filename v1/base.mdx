The Base API shows the API's name and current version. You can try it without an account or API key.

## Try it

Use the interactive request panel on this page, open [the API address](https://api.alexxweb.com/api/v1) in your browser, or run:

<CodeGroup>

```powershell cURL
curl https://api.alexxweb.com/api/v1
```

```javascript JavaScript
const response = await fetch("https://api.alexxweb.com/api/v1");
const api = await response.json();
console.log(api);
```

```python Python
import json
from urllib.request import urlopen

with urlopen("https://api.alexxweb.com/api/v1") as response:
    print(json.load(response))
```

</CodeGroup>

## What you'll see

```json
{
  "name": "AlexWeb API",
  "version": "1.2.0"
}
```

- **name** is the API's name.
- **version** is the current API version.

This request only reads information. It does not change anything.

## Connect your app

<Steps>
  <Step title="Get access">
    [Create a developer account](/v1/developer-accounts) and make your first key in the console. Public information is open to everyone; your account's data needs an [API key](/v1/api-keys) or [OAuth token](/v1/oauth).
  </Step>
  <Step title="Choose permissions">
    Give each app the permissions it needs, such as `resources:read`. A separate key for each app makes it easier to replace or revoke access later.
  </Step>
  <Step title="Try a useful request">
    [Create a resource](/v1/resources#try-it), read it from another app, then use [events](/v1/events) to keep both apps up to date.
  </Step>
</Steps>

## Explore the API

Each major API page has a request panel linked to the live OpenAPI specification. Read requests show your current data. Sending a create, update, or delete request changes real data in the account connected by your credential.

For a public POST example, try the existing [Echo endpoint](/echo-endpoint). For a full list of request fields and response models, download the [OpenAPI specification](https://api.alexxweb.com/openapi.json).

| Request | What it does |
| --- | --- |
| `GET /api/v1` | Shows the API's name and version. |
| `GET /api/v1/health` | Checks whether the API can read its storage. |
| `GET /api/v1/status` | Shows readiness, uptime, and storage response time. |
| `GET /api/v1/capabilities` | Lists available API features and limits. |
| `GET /openapi.json` | Downloads the full API specification. |

These requests are public.
