The Base API shows the API's name and current version.

## Try it

Open [https://api.alexxweb.com/api/v1](https://api.alexxweb.com/api/v1) in your browser, or run:

<CodeGroup>

```powershell CURL
curl https://api.alexxweb.com/api/v1/
```

</CodeGroup>

You do not need to log in or provide an API key.

## What you'll see

```json
{
  "name": "AlexWeb API",
  "version": "1.1.0"
}
```

- **name** is the API's name.
- **version** is the current API version.

This request only reads information. It does not change anything.

## Other useful requests

| Request | What it does |
| --- | --- |
| `GET /health` | Checks whether the API is running. |
| `GET /api/v1/capabilities` | Lists available API features and limits. |
| `GET /openapi.json` | Downloads the full API specification. |

These requests are public. To manage data, use an [API key](/v1/api-keys) or an [OAuth token](/v1/oauth).
