The API is ready to share **AlexWeb resources and events** with Home Assistant.

<Info>
  The Home Assistant integration itself will be built later. There is nothing to install in Home Assistant yet.
</Info>

This support exposes data stored in AlexWeb. It does not connect your existing Nest thermostats, Denon receiver or Homebridge devices.

## Try it

A snapshot loads the current entities and an event cursor together. Your credential needs `resources:read`, `events:read` and `integrations:read`.

<CodeGroup>

```powershell CURL
curl https://api.alexxweb.com/api/v1/integrations/home-assistant/snapshot -H "Authorization: Bearer YOUR_API_KEY"
```

</CodeGroup>

## What you'll see

The response contains **entities** and a **cursor**.

- **entities** represents your AlexWeb resources as sensors, binary sensors, switches or text values. Only switches and text values accept commands from this integration.
- Each entity has a stable ID based on its resource ID.
- **cursor** lets the integration read updates without missing changes during setup.

The future integration will use the domain `alexweb_api`. It can authenticate with an API key or OAuth with S256 PKCE.

## Send a command

This changes an AlexWeb switch resource. It needs all three read permissions above, plus `resources:write`.

<CodeGroup>

```powershell CURL
curl https://api.alexxweb.com/api/v1/integrations/home-assistant/commands -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" -d '{"resourceId":"RESOURCE_ID","command":"set_state","state":true,"version":1}'
```

</CodeGroup>

The **version** field is required. Use the version you last read to protect against overwriting a newer state. An outdated version returns **412**.

## Other requests

| Request | What it does | Required scopes |
| --- | --- | --- |
| `GET /api/v1/integrations/home-assistant/manifest` | Public integration discovery and readiness. | None |
| `GET /api/v1/integrations/home-assistant` | Reads integration information. | `integrations:read`, `resources:read`, `events:read` |
| `GET /api/v1/integrations/home-assistant/entities` | Lists compatible entities. | `integrations:read`, `resources:read`, `events:read` |
| `GET /api/v1/integrations/home-assistant/snapshot` | Loads entities and an event cursor together. | `integrations:read`, `resources:read`, `events:read` |
| `POST /api/v1/integrations/home-assistant/commands` | Sets a switch or text resource's state. | All three read scopes, plus `resources:write` |

After loading a snapshot, use [event polling or streaming](/v1/events) for updates. A 30-second poll interval is a useful starting point. If the API returns **410**, load a new snapshot and continue from its cursor.
