  Home Assistant OS is recommended, as this tutorial uses bash to install the integration.
</Warning>

<Steps>
  <Step title="Go to [Terminal & SSH Installer](https://my.home-assistant.io/redirect/_change/?redirect=supervisor_app%2F%3Fapp%3Dcore_ssh)">
  </Step>
  <Step title="Enter your Home Assistant instance address">
    Click Home Assistant URL, then enter your instance URL.
  </Step>
  <Step title="Press Save / Change">
  </Step>
  <Step title="Press Open Link">
  </Step>
  <Step title="Press Install">
    When you press install, the app will take a moment to install, so wait patiently.

    <Warning>
      If the app takes longer than 3 minutes, refresh and press install again.

      If this does not work, restart your Home Assistant instance.
    </Warning>
  </Step>
  <Step title="Go to the Configuration tab">
  </Step>
  <Step title="Add a package">
    In the input field, write curl, and press enter or done.
  </Step>
  <Step title="Press Save on the Options window">
  </Step>
  <Step title="Go to the Info tab">
  </Step>
  <Step title="Enable Watchdog">
  </Step>
  <Step title="Enable Auto Update">
  </Step>
  <Step title="Enable Show in Sidebar">
    <Warning>
      This is very important that you enable it.
    </Warning>
  </Step>
  <Step title="Press Start">
    After pressing start, wait a moment.

    Refresh your page, and make sure it says running and there is a stop and restart button.
  </Step>
  <Step title="Press Open Web UI">
  </Step>
  <Step title="Run Commands Below:">
    ```shellscript
    apk update all
    curl -V
    ```

    <Warning>
      If curl -V returns an error, run  `apk install curl`
    </Warning>
  </Step>
