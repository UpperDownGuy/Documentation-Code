This quickstart walks you through calling the AlexWeb API for the first time: you get a key, send an authenticated request, and check the response.

## Prerequisites

- An AlexWeb account
- `curl` or any HTTP client

<Steps>
  <Step title="Get your API key">
    Create an API key in your dashboard. See [Authentication](/authentication) for details.
  </Step>
  <Step title="Send a request">
    Replace the placeholders with your base URL, endpoint, and key.

    ```bash Terminal
    curl https://api.example.com/v1/YOUR_ENDPOINT \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```
  </Step>
  <Step title="Check the response">
    A successful request returns a `200` status code with a JSON body.

    ```json Response
    {
      "TODO": "Add a real example response"
    }
    ```
  </Step>
</Steps>

<Note>
  Replace `https://api.example.com/v1` and `YOUR_ENDPOINT` with AlexWeb's real base URL and an endpoint from the [API Reference](/api-reference/introduction).
</Note>
