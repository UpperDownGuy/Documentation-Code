This guide takes you from an API key to a small working AlexWeb integration in your own code, including basic error handling.

## Prerequisites

- An AlexWeb API key ([Authentication](/authentication))
- Node.js 18+ or Python 3.9+

<Steps>
  <Step title="Store your API key">
    ```bash Terminal
    export ALEXWEB_API_KEY="YOUR_API_KEY"
    ```
  </Step>
  <Step title="Call the API">
    <CodeGroup>

    ```javascript index.js
    const res = await fetch("https://api.example.com/v1/YOUR_ENDPOINT", {
      headers: { Authorization: `Bearer ${process.env.ALEXWEB_API_KEY}` },
    });
    if (!res.ok) throw new Error(`Request failed: ${res.status}`);
    console.log(await res.json());
    ```

    ```python main.py
    import os, requests
    
    res = requests.get(
        "https://api.example.com/v1/YOUR_ENDPOINT",
        headers={"Authorization": f"Bearer {os.environ['ALEXWEB_API_KEY']}"},
    )
    res.raise_for_status()
    print(res.json())
    ```

    </CodeGroup>
  </Step>
  <Step title="Handle errors">
    Check the status code and follow the guidance in [Errors](/concepts/errors).
  </Step>
</Steps>

<Note>
  Replace the base URL and endpoint with real values from the [API Reference](/api-reference/introduction).
</Note>
