## Status codes

| Code | Meaning | What to do |
| --- | --- | --- |
| `200` | Success | No action needed |
| `400` | Bad request | Fix the request parameters |
| `401` | Unauthorized | Check your API key |
| `403` | Forbidden | Use a key with the right permissions |
| `404` | Not found | Check the resource ID or path |
| `429` | Too many requests | Wait and retry with backoff |
| `500` | Server error | Retry later |

## Error response format

```json Example error
{
  "error": {
    "code": "TODO_error_code",
    "message": "Human-readable description of the error"
  }
}
```

## Retries

<Tip>
  Retry `429` and `5xx` responses with exponential backoff. Do not retry `4xx` errors other than `429` without changing the request.
</Tip>
